# OA_GET 浏览器插件

这是一个用于爬取吉林大学电子校务平台最近24小时通知的Edge浏览器插件。

## 功能特点

- 每天第一次打开浏览器时自动爬取并显示最近24小时发布的通知
- 显示通知名称、发布单位、发布时间，并提供超链接
- 支持手动刷新查看最新通知
- 智能识别并过滤最近24小时内发布的通知

## 安装方法

1. 打开Edge浏览器，输入 `edge://extensions/` 进入扩展管理页面
2. 开启右上角的"开发者模式"
3. 点击"加载解压缩的扩展"
4. 选择本项目的文件夹（包含manifest.json的目录）
5. 插件已安装完成，图标将显示在浏览器工具栏中

## 技术说明

- 使用Chrome扩展Manifest V3标准开发
- 采用16x16和48x48两种尺寸的图标确保兼容性
- 实现了智能时间判断算法，支持多种时间格式（今天、昨天、具体日期）
- 精确计算时间差，确保只显示最近24小时内的通知
- 使用Storage API缓存通知数据，提升性能和用户体验

## 使用方法

1. 每天第一次打开浏览器时，插件会自动爬取通知并弹出窗口显示
2. 点击浏览器工具栏中的插件图标，可以手动查看今日通知
3. 点击"刷新通知"按钮可重新爬取最新通知
4. 点击通知标题可跳转到原始通知页面

## 技术说明

- 使用Chrome扩展Manifest V3标准开发
- 通过background.js实现定时爬取和浏览器启动自动检查
- 使用storage API存储爬取结果
- 界面采用现代化设计，支持响应式布局

## 注意事项

- 本插件仅爬取公开可访问的通知信息
- 请确保网络连接正常以获取最新通知
- 如果爬取失败，可以尝试手动刷新
